# Sanctions Screening Dashboard

This project analyzes synthetic customer, transaction, and screening data to identify potential sanctions-screening matches and support compliance decision-making.

## Objective
To practice compliance analytics using Excel, SQL, and Power BI.

## Tools Used
- Excel
- SQL
- Power BI
- GitHub

## Dataset
The dataset is synthetic and created for learning purposes. No real customer, bank, or company data is used.

## Project Workflow
1. Create and clean sample customer, transaction, and screening data.
2. Analyze screening results using SQL.
3. Build an interactive dashboard in Power BI.
4. Identify high-risk customers, screening matches, and potential false positives.

## Key Features
- Customer risk analysis
- Sanctions screening results
- Potential match tracking
- Transaction analysis
- Interactive dashboard

## Status
In progress.
